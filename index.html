プライバシーポリシー

1. はじめに

受術回線（以下「本アプリ」）は、スマートフォンの通信状態を「接続術式」「帯域出力」「遅延ノイズ」「受信領域」などの表現で表示する、ネットワーク診断エンタメアプリです。

現在のクローズドテスト版では、一部の診断値に表示確認用の仮データを使用しています。

2. 取得する情報

本アプリは、アプリの機能提供のため、以下の情報を端末内で使用する場合があります。

  • 端末のネットワーク接続状態
  • インターネット接続の有無
  • 簡易的な通信診断結果
  • アプリ内設定
  • 診断表示に必要な一時的な情報

これらの情報は、診断結果の表示や画面演出のために使用します。

3. 取得しない情報

本アプリは、以下の情報を取得しません。

  • 通信内容
  • パケット内容
  • 個人情報
  • 氏名
  • メールアドレス
  • 連絡先
  • 写真
  • ファイル
  • マイク音声
  • カメラ映像
  • 他人の通信データ

また、本アプリは「傍受術式」という世界観上の名称を使用しますが、実際に通信内容を傍受、盗聴、解析する機能はありません。

※ ただし「Wi‑Fi領域観測」機能を使用する場合に限り、測定中のみ位置情報を利用します。詳細は下記「5. Wi‑Fi領域観測機能について」をご確認ください。

4. 利用目的

本アプリが端末内で扱う情報は、以下の目的で使用されます。

  • 通信状態の表示
  • 診断結果の表示
  • 診断演出の表示
  • 共有画像の生成
  • アプリ内設定の保存

5. Wi‑Fi領域観測機能について

0.3.3 以降で追加された「Wi‑Fi領域観測」機能を利用する場合に限り、以下の情報を扱います。この機能を使わない場合、これらの権限・情報は不要で、通常の診断機能は位置情報などの追加権限なしで利用できます。

  • 位置情報の利用は、Wi‑Fi領域観測を使用した場合のみです。ホーム等の通常機能では位置情報を利用しません。
  • 位置情報は、アプリの使用中（測定画面を表示している間）のみ取得します。
  • バックグラウンドでの位置情報取得は行いません。バックグラウンドへ移行すると測定は停止します。
  • 測定では、周辺Wi‑Fiの信号強度（受信強度）を利用します。
  • 通信内容やパケット内容、閲覧履歴は取得しません。
  • 緯度・経度を永続保存しません。緯度・経度は測定中に開始地点からの相対座標へ変換するためだけにメモリ上で使用します。
  • Wi‑Fiの生のSSID / BSSIDを長期保存しません。一覧表示のための一時的な処理にのみ用い、端末内の測定結果には含めません。
  • 測定結果として端末内に保存するのは、開始地点を原点とした相対座標（メートル）と受信強度（RSSI）等の、絶対的な位置を復元できない値のみです。
  • 測定結果を独自サーバー・外部サーバーへ送信しません。Wi‑Fi領域観測の測定は端末内で完結します（広告配信のためのデータ処理については第8章をご覧ください）。
  • 保存した測定セッションは、ユーザーがいつでも結果画面から削除できます。
  • 通常の診断機能は、位置情報などの追加権限がなくても利用できます。

使用する権限: ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION（測定中の端末位置・前景のみ）、NEARBY_WIFI_DEVICES（Android 13以降・周辺Wi‑Fiスキャン・neverForLocation を宣言）、ACCESS_WIFI_STATE / CHANGE_WIFI_STATE（Wi‑Fiスキャン）。ACCESS_BACKGROUND_LOCATION は要求しません。

English (Wi‑Fi Field Survey)

The following applies only when you use the Wi‑Fi Field Survey feature. Normal diagnosis features work without any additional permissions such as location.

  • Location is used only when you use Wi‑Fi Field Survey; normal features do not use location.
  • Location is collected only while the app is in use (while the measurement screen is shown).
  • No background location is collected; measurement stops when the app goes to the background.
  • The measurement uses the signal strength of nearby Wi‑Fi.
  • We do not access communication content, packet content, or browsing history.
  • We do not permanently store latitude/longitude; they are used only in memory to compute relative coordinates from the starting point.
  • We do not store raw Wi‑Fi SSID/BSSID long‑term.
  • We store only values that cannot reconstruct an absolute position: relative coordinates (meters) and RSSI, etc.
  • We do not send measurement results to our own or any external server; Wi‑Fi Field Survey stays entirely on the device (see section 8 for data processed for advertising).
  • Saved sessions can be deleted by the user at any time from the result screen.
  • Normal diagnosis features work without location or other extra permissions.

6. 外部送信について

本アプリは、独自のサーバーを持たず、ユーザーデータを当方のサーバーへ送信しません。 診断結果・診断履歴・Wi‑Fi領域観測の測定結果は端末内で処理・保存されます。

ただし、広告配信のために Google Mobile Ads SDK（AdMob）が Google へデータを送信します。 この一点のみ端末内で完結しません。詳細は第8章をご覧ください。

The app has no server of its own and sends no user data to us. Diagnosis results, history and Wi‑Fi Field Survey measurements are processed and stored on your device. The one exception is advertising: the Google Mobile Ads SDK (AdMob) sends data to Google. See section 8.

7. 第三者サービスについて

本アプリは、以下の第三者サービスを利用しています。

  • Google Mobile Ads SDK（AdMob） — バナー広告の配信に利用しています（利用中）。
  • Google User Messaging Platform（UMP） — 広告配信に関する同意の取得・管理に利用しています（利用中）。
  • Google Play Services — アプリの動作基盤として利用しています。
  • Google Play Billing — 現時点では利用していません（アプリ内課金は提供していません）。

これらのサービスでは、各サービス提供者のプライバシーポリシーおよび利用規約に基づいて情報が処理されます。 Google のプライバシーポリシー: https://policies.google.com/privacy ／ Google のサービスを使用するサイトやアプリからの情報の利用: https://policies.google.com/technologies/partner-sites

8. 広告について

本アプリは無料で提供するため、一部の画面（ホーム・診断結果）にバナー広告を表示します。 広告配信には Google の Google Mobile Ads SDK（AdMob） を使用します。

  • 広告配信のため、Google Mobile Ads SDK は IP アドレス・端末や広告の識別子（広告 ID 等）・アプリの利用状況（広告の表示や操作）・診断情報 を収集し、Google と共有します。これらは広告配信、広告の効果測定・分析、不正防止とセキュリティのために利用されます。
  • IP アドレスから、市区町村程度のおおよその位置が推定される場合があります。 これは広告配信のために Google 側で行われる処理であり、本アプリが端末の位置情報（GPS 等）を広告のために取得・送信しているわけではありません。
  • 広告 ID は端末の設定からいつでもリセット・削除できます（Android の「設定 > プライバシー > 広告」）。
  • Wi‑Fi領域観測の測定結果（相対座標・受信強度）や診断履歴を広告配信に利用しません。 これらは端末内にのみ保存され、広告 SDK へ渡していません。
  • SSID / BSSID・緯度経度・通信内容を広告のために送信することはありません。

広告に関する同意（UMP）

  • EU/EEA・英国・スイスなど、同意の取得が必要な地域では、Google の User Messaging Platform（UMP） を用いて広告配信に関する同意を取得します。
  • 同意が得られるまで広告のリクエストは行いません。 同意が得られない場合、広告は表示されず、アプリの機能は通常どおり利用できます。
  • 同意の内容は、アプリ内の 設定 > 広告プライバシー設定 からいつでも変更できます（この項目は、再設定が提供されている地域でのみ表示されます）。
  • 通信できない環境などで同意の取得に失敗した場合も、広告を表示しないだけで、診断・Wi‑Fi領域観測の機能はそのまま利用できます。

9. 免責事項

「一部の診断値」は表示確認用の仮データを含む場合があります。
